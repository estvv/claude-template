## Système de score

- 1 achivement = X points (décidé par la communauté)
- faire l’achievement → donne des points
- faire en premier → donne + de point → Puis dégressif
    - Exemple: 1er = 50 points, 2ème = 40, 3ème = 25

## Création d’achievement:

- Si user X créer un event, il a un délais de X jours pour le réaliser
- Ping sur discord
    - Estimation du nombre de points donnés après vote
- Selection dans quel Groupe il sera créer

## Système de validation:

- Si achievement validé → preuve par photo / vidéo / voice / screen
- Validation par la communauté
    - Possibilité de mettre un nb de point inférieur / Supérieur
    - Possibilité de mettre 0 / Gratuit → si + de la moitié alors achievement ne rapporte aucun point mais est disponible
- Possibilité d’ajouter une note à l’achievement fait
- Possibilité de commenter les achievements des autres

## Système de Groupe

- Un utilisateur peut être dans plusieurs groupes
- Un utilisateur a un score différent dans chaque groupes
- Un utilisateur a des achievements différents dans chaque groupe

## Leaderboard

- Ptit leaderboard présent et accessible dans l’appli pour voir le + gros achiever (par groupe)
- Possibilité de trier leaderboard par catégorie

## Gambling

- Un utilisateur peut créer des paris (exemple: cette personne là réaliser cet achievement en premier)
- Les autres users / lui même peuvent parier des points sur ce pari

## Monnaie

- Score des achievements → **Karma**
- Monnaie des paris → **Tokens**

# Notifications

- Notif une personne quand pas achievement depuis 1 mois (violent)

# Calendrier

- Tout achievements d’un groupe sera dessus
